# Power BI automation options - what was verified (2026-10-12)

"Verified" = I read Microsoft's documentation (dates noted) or actually ran it. "Not tested" = no Power BI Desktop / account was available.
Environment: Windows 11, Node 24, .NET 8 runtime (no SDK), PowerShell 5.1, **no Power BI Desktop, no Power BI/Fabric account used**.

## Conclusion
The strongest *legitimate* automation is **#1 (+ #6 for validation)**: generate and validate a complete PBIP project in code. A genuine `.pbix` still needs
Power BI Desktop for one step (open the `.pbip`, Refresh, **File > Save as > .pbix**). The Desktop Bridge (#2) can then capture real screenshots of every page,
but it cannot save the `.pbix`.
