## Remaining discrepancies between report and implementation
1. Power BI is now the dashboard and matches the original files; it imports CSV exports and does not connect to HDFS (the report's architecture shows HDFS feeding Spark; Power BI sits after the Spark/MLlib outputs, via CSV).
2. HDFS replication factor 3 / fault tolerance cannot be shown on one node.
3. Report's best Random Forest setting (100 trees, depth 20, val AUC 0.759) is not reproduced: infeasible on a 16 GB laptop with a 3 GB driver; best measured is 50 trees, depth 15 (val AUC 0.7549).
4. Report Figures 4-5 (PCA, elbow) were drawn from scikit-learn runs and are unchanged in the v3 copy; regenerated Spark versions are `faculty_evidence/report_aligned/kmeans_pca.png` and `kmeans_elbow_silhouette.png`.
5. Report "Linear Regression ... Evaluated here: No" is still true of the report body; its results are in the repository (stated in section 1.1 of the v3 copy).
6. `models/*.joblib` were pickled with scikit-learn 1.9.0 and load under the installed 1.8.0 with an `InconsistentVersionWarning` (works; pinning 1.9.0 is advisable).
7. Dashboard Logistic Regression ROC-AUC (0.755) was not re-measured.
